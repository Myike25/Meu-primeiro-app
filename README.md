# App de Gestão de Frota e Despesas

Aplicativo mobile desenvolvido para gerenciamento de frotas veiculares, acompanhamento de viagens e controle de despesas operacionais.

##  Tecnologias Utilizadas
- **Linguagem:** JavaScript / TypeScript
- **Framework Mobile:** React Native (Expo)
- **Editor:** VS Code

##  Funcionalidades (Em Desenvolvimento)
-  Cadastro e listagem de veículos
-  Registro e controle de custos/despesas
-  Interface mobile intuitiva e responsiva
